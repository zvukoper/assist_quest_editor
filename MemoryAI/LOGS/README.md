# Диагностические логи

Эта папка используется как временный контейнер для логов, которые пользователь собирает для анализа текущей проблемы.

## Правила

- README.md не удаляется.
- CI_errors.md перезаписывается каждым прогоном `ci/run_local.ps1` (сводка проверок, причины ошибок и полный вывод упавших проверок).
- Остальные файлы содержимого папки очищаются после успешной сборки.
- Журналы (`*.log`, `CI_errors.md`) отслеживаются git и попадают в коммит: исключать их из репозитория больше не нужно, поскольку CI запускается только вручную.
- В рабочем состоянии приложение должно уметь собирать сюда необходимые журналы кнопкой на основной форме.
- app_workflow содержит подробную последовательность выполнения.
- app_data содержит потенциально шумные снимки значений.
- Не складывать сюда секреты, пароли и токены.
