Сейчас в AQE есть интерфейс, где  нужно выбрать имя. Туда нужно добавить возможность авторизироваться через стим. То есть нажимаем кнопку авторизации в стим и в приложение поступает никнейм из стима. Если для этого потребуется веб-авторизация, то авторизацию выоплнять через системный браузер по умолчанию. На этой машине это хром. При этом в авторство файлов прописывается никнейм профиля и ссылка на него.
